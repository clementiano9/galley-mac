## Verified Non-Issues (checked, not problems)

- **Edit textarea text contrast**: `--tv-text-primary` on transparent (inherits `--tv-bg-primary`): light 16.25:1, dark 13.55:1. Both pass easily.
- **Edit textarea caret visibility**: `caret-color: var(--tv-accent)` explicitly set for both themes (`tv-app.css:792-793`). Light blue caret on bg-primary = 4.97:1, dark blue = 6.19:1. Both visible.
- **Edit textarea padding lateral alignment**: `.tv-edit-area` side padding `var(--tv-s7)` = 40 px matches `.tv-content` side padding exactly. No horizontal jump on edit/read toggle.
- **Sidebar resizer hidden when collapsed**: `tv-app.css:166` — `.tv-sidebar.collapsed { display:none }` removes the entire sidebar (including resizer). No separate hide rule needed.
- **Resizer `cursor:col-resize`**: confirmed at `tv-app.css:177`.
- **`tv-titlebtn` focus-visible contrast**: 2 px accent outline: light 4.23:1 (passes WCAG 1.4.11 non-text 3:1); dark 5.07:1. Adequate.
- **Find bar `tv-find-hit` contrast**: light blue `#1f55c0` on effective accent-weak `#e0e8f6` = 5.46:1 (passes). Dark blue `#7fb0ff` on effective dark accent-weak `#273347` = 5.79:1 (passes).
- **Recent row base contrast**: light `#6b6b72` on `#f3f3f1` = 4.76:1 (passes before opacity); dark 6.30:1 (passes).
- **Wintitle centering (Tauri)**: L-14 fix confirmed — `html.tauri .tv-wintitle { margin-right: 84px }` in `tv-tauri.css:35-37` balances the 84 px left padding exactly.
- **Find bar `button:focus-visible` coverage**: `.tv-find-nav` and `.tv-find-close` are `<button>` elements; `button:focus-visible` at `tv-app.css:1093` covers them.
- **`tv-titlebtn` `button:focus-visible` coverage**: `.tv-titlebtn` is a `<button>`; covered by `button:focus-visible` at `tv-app.css:1093`.
- **`prefers-reduced-motion` existing animations**: bolt pulse, blip, shimmer, carets, diagram fade, toast slide all suppressed correctly.
