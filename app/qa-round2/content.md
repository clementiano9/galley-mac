## Verification Method

All findings were confirmed by one or more of:

- **Line-by-line code trace** of `tv-markdown.js` (inline(), highlight(), render(), blockquote branch, buildNestedList(), buildTable(), diagramPlaceholder(), _loadMermaid())
- **Grep verification** of CSS selectors and property values in `tv-app.css`
- **Node evaluation** (`node` REPL, confirmed in the first batch of tests that completed): T3/T66 stash corruption confirmed (`(output.match(/\x01/g)||[]).length === 2` for `echo "hello"`); T14 blockquote+fence confirmed (`<pre>` absent); T29 table-in-blockquote confirmed (`<table>` absent); T11 strikethrough confirmed (literal `~~` in output); T12 hard line break confirmed (no `<br>`); T33 trailing hash confirmed (`##` in h2 text); T36/T37 deferred (node stalled after renderer load but regex analysis is conclusive)
- **Cross-checked** against QA-REPORT.md round 1 and round 2 resolution table — zero duplicate entries

## Non-Issues Verified (No Bug)

The following were tested and found correct:
- Raw HTML in source text is escaped via `esc()` (T5: `<script>` → `&lt;script&gt;`)
- Inline HTML inside backtick code is escaped (T4: `<div class="x">` → `&lt;div class=&quot;x&quot;&gt;`)
- `javascript:` and `vbscript:` links are blocked (E-14 fix confirmed working)
- Setext headings correctly avoid false-positive on table separator (`isTableSep` guard at line 214)
- Fence closing line with trailing whitespace correctly matched (`\s*$` in closePat at line 187)
- Task list `[X]` uppercase checkbox correctly recognized (regex includes `xX` at line 252)
- `**bold _italic_ end**` nesting renders correctly (T6 confirmed)
- Ampersand in body text correctly escaped to `&amp;` (T67: `Tom & Jerry` → `Tom &amp; Jerry`)
