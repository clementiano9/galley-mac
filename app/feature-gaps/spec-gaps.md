## Notes on scope

- **F-01 (Cmd+[/])** is the highest-discoverability gap after the theme toggle issue: it is the only keyboard navigation method in the IA that is completely absent from the keyboard router.
- **F-03 (Open Folder)** requires both a new Rust command and a JS integration — the most substantial remaining feature gap.
- **F-07 (in-document find)** and **F-08 (native menu bar)** are independently critical for App Store submission. Without a menu bar the app violates macOS HIG.
- **F-17 (scroll persistence across restarts)** is a subtle gap: DR-03 says "per-file across tab switches" which technically the code meets, but the intent of the flow models implies cross-launch persistence.
- F-18, F-19, F-20, F-21, F-22 are quality-of-life additions well-supported by the spec but not strictly blocking a functional first release.
